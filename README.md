# Personal Portfolio


A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Run locally

From this project folder, run:

```bash
python3 -m http.server 3000
```

Then open:

```text
http://localhost:3000
```

## Files

- `index.html` — page markup and content sections
- `styles.css` — layout, theme, and responsive styling
- `script.js` — mobile menu behavior and dynamic year
